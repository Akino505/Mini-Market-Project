# styled-components против CSS Modules на моём проекте
1. Варианты и размеры кнопок у меня описаны объектами `variants` и `sizes` и выбираются через `$variant` и `$size`, а в CSS Modules для этого понадобился бы отдельный класс на каждое значение и склейка через `clsx`.
2. Тема доступна прямо в JS, и переключение сводится к замене объекта в `ThemeProvider`, а на CSS-переменных то же самое делается сменой атрибута на `<html>`, и браузер пересчитывает `var()` без участия React.
3. Стили лежат рядом с компонентом, поэтому мёртвых классов не остаётся: при удалении компонента - удаляются соответствующие стили, а `.module.css` пришлось бы чистить отдельно.
4. Тема типизирована через `DefaultTheme`, поэтому опечатка вроде `theme.colors.primery` не проходит компиляцию, тогда как `styles.titel` или `var(--color-primery)` в CSS Modules промолчали бы.
